title: What are handlers?
---
Handlers are game specific scripts and files that tell Nucleus Co-op how to run multiple instances of a particular PC game on the same computer, allowing multiple players to play together locally, usually in split-screen. A handler tells the program how and what to open, edit and use. It is a set of instructions that controls how Nucleus interacts with the game, its files, processes, windows and input devices. Basically if you want to split-screen a game you need a handler to tell Nucleus Co-op how to split-screen it. 

See [Which games are supported?](https://www.splitscreen.me/docs/games).

For more information on how to make a handler yourself, please see [How do I create my own split-screen handler for Nucleus Co-op?](https://www.splitscreen.me/docs/faq#17--how-do-i-create-my-own-split-screen-handler-for-nucleus-co-op).
